# HuggingFace Spaces runtime dependencies for AARA Trading Intelligence
# (applications/trading_intelligence/) — kept minimal, no ML/trading packages.
#
# gradio==4.44.1, not dashboard/'s 5.9.0 (requirements_space.txt):
# PyPI metadata confirms gradio 5.9.0 requires Python >=3.10, while 4.44.1
# supports Python >=3.8. applications/trading_intelligence/'s test suite
# (272 tests) and its Decision Center UI's documented Gradio-4.44.1-specific
# keyboard-selection behavior (see gradio_view.py's own module docstring,
# "Gradio 4.44.1's Dataframe keyboard gap") have only ever been run against
# this exact version — 5.9.0 compatibility is unverified. Do not upgrade
# this pin without re-verifying that behavior against the new version.
gradio==4.44.1
pillow>=10.4.0

# gradio==4.44.1 declares only huggingface-hub>=0.19.3 (no upper bound), so
# an unpinned install picks up the latest huggingface_hub -- which removed
# HfFolder starting at 1.0.0 (verified against GitHub source at each tag:
# present through v0.36.2, gone at v1.0.0 and every release since). gradio
# 4.44.1 imports HfFolder internally (gradio/oauth.py) and crashes on start
# without it -- confirmed via the actual HF Space runtime traceback
# (ImportError: cannot import name 'HfFolder' from 'huggingface_hub').
# 0.36.2 is the narrowest pin: the exact last release that still has it.
huggingface_hub==0.36.2

# gradio==4.44.1 declares no direct starlette pin; it depends on fastapi<1.0,
# and unpinned fastapi (0.141.1) pulls starlette>=0.46.0's latest -- 1.6.0,
# which dropped the deprecated TemplateResponse(name, context_dict) calling
# convention gradio/routes.py:432 uses (starlette>=1.0.0 keeps only the new
# TemplateResponse(request, name, context) signature). Confirmed directly
# against starlette source: 0.52.1's TemplateResponse still special-cases
# `isinstance(args[0], str)` to correctly unpack the old-style (name, dict)
# call gradio makes; that branch is gone starting at 1.0.0, which is why
# jinja2 ends up handed a dict as the template name (TypeError: unhashable
# type: 'dict') -- confirmed via the actual HF Space runtime traceback.
# 0.52.1 is the latest starlette release still containing that shim.
starlette==0.52.1
